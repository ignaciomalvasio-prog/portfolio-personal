# Portfolio personal

App web instalable que muestra el sheet PORTFOLIO PERSONAL. El código está acá; los números no:
la app los pide al sheet a través de un script de Google protegido con clave.

## Puesta en marcha (una sola vez)
1. En el sheet: Extensiones > Apps Script. Pegá `apps-script.gs`, cambiá `CLAVE` y guardá.
2. Implementar > Nueva implementación > Aplicación web. Ejecutar como: yo. Quién tiene acceso: cualquier usuario. Copiá la URL que termina en `/exec`.
3. Abrí la app en el celular, pegá la URL y la clave.
4. Agregar a pantalla de inicio (Safari: Compartir > Agregar a inicio; Chrome: menú > Instalar app).
